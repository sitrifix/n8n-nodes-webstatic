# n8n-nodes-webstatic

An [n8n](https://n8n.io) community node package that lets you **host HTML pages directly from your workflows** — no external web server required.

[![npm version](https://img.shields.io/npm/v/n8n-nodes-webstatic)](https://www.npmjs.com/package/n8n-nodes-webstatic)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## Nodes included

### Web Static Trigger

A **trigger node** that serves a fixed HTML page at a webhook URL.
On every visit, it also fires the downstream workflow with visitor metadata.

**Use cases:** landing pages, status pages, link-in-bio pages, simple dashboards written directly in the node.

| Property | Description |
|---|---|
| **Path** | URL suffix — page is served at `[n8n-host]/webhook/<path>` |
| **HTML Content** | Full HTML (supports n8n expressions) |
| **Authentication** | None or Basic Auth (username + password) |
| **Additional Headers** | Optional extra HTTP response headers |

**Output (on each visit)**

```json
{
  "timestamp": "2026-03-14T14:35:00.000Z",
  "ip": "1.2.3.4",
  "userAgent": "Mozilla/5.0 ...",
  "path": "/webhook/my-page",
  "query": {}
}
```

### Web Static Page

A **trigger node** that serves a persistent HTML page and accepts updates via HTTP POST.

- **`GET /webhook/<path>`** — serves the last stored HTML (or a placeholder before the first update)
- **`POST /webhook/<path>`** — receives `{ "html": "..." }` and stores it; triggers the downstream output

The page stays live between workflow runs, always showing the **last pushed content**.

**Use cases:** weekly reports, dashboards built from API data, any page whose content is generated by a workflow.

**Setup (two separate workflows)**

**Workflow A — serves the page (keep active)**
```
[Web Static Page]  →  (On Update)  →  [optional: Slack / log]
   path: journal
```

**Workflow B — generates and pushes content (runs on schedule)**
```
[Schedule]  →  [Code: build HTML]  →  [HTTP Request]
 Every Monday   { html: "..." }       POST [n8n-host]/webhook/journal
                                      Body: JSON → { "html": "{{ $json.html }}" }
```

| Property | Description |
|---|---|
| **Path** | URL suffix — page served at `[n8n-host]/webhook/<path>` |
| **Authentication** | None or Basic Auth (applies to GET only) |
| **Additional Headers** | Optional extra HTTP response headers on GET |

**Output (On Update)** — fires each time a POST updates the page:
```json
{
  "event": "html_updated",
  "lastUpdated": "2026-03-14T14:35:00.000Z",
  "path": "journal",
  "htmlLength": 4821
}
```

The GET response includes an `X-Last-Updated` header with the ISO timestamp of the last update.

## How it works

Both nodes register webhooks with n8n's internal engine — the same mechanism used by the built-in Form node. No extra ports or processes are needed.

`Web Static Page` uses n8n's **node static data** (`getWorkflowStaticData`) to persist the HTML between workflow executions. This data is stored in the n8n database and survives restarts.

## Installation

### Via the n8n UI (recommended)

1. Go to **Settings → Community nodes**
2. Search for `n8n-nodes-webstatic`
3. Click **Install**

### Manually (self-hosted)

```bash
# In your n8n custom nodes directory (~/.n8n/nodes)
npm install n8n-nodes-webstatic
```

Then restart n8n.

---

## Development & Docker

Clone the repository and start a local n8n instance with the node pre-loaded:

```bash
git clone https://github.com/sitrifix/n8n-nodes-webstatic.git
cd n8n-nodes-webstatic
docker compose up --build
```

n8n will be available at **http://localhost:5678** (first run asks you to create an owner account).

To rebuild after editing the source:

```bash
docker compose down
docker compose up --build
```

### Local build (without Docker)

```bash
npm install --ignore-scripts   # skip native addon compilation
npm run build                  # tsc + copy SVG icons
```
